# design-sync notes — Envíos DosRuedas

## How this repo is built for Claude Design

- The repo is a Next.js 16 app, not a published package. `.design-sync/build/build-ds.mjs` (= `cfg.buildCmd`) builds a
  real mini-package into `.ds-pkg/` (gitignored): esbuild ESM of `.design-sync/build/entry.ts` (re-exports
  `src/components/ui`), tsc declarations (`tsconfig.dts.json`), Tailwind v4 CSS compiled from the real
  `src/app/globals.css` (scanning the whole repo + `.design-sync/previews/`), brand fonts from `.design-sync/fonts/`.
- It needs `.ds-sync/node_modules` (esbuild) — run the staged-script install first:
  `cd .ds-sync && npm i esbuild ts-morph @types/react playwright@1.62.1`.
- Converter: `node .ds-sync/package-build.mjs --config .design-sync/config.json --node-modules ./node_modules --out ./ds-bundle`
  (entry comes from `cfg.entry` = `.ds-pkg/dist/index.js`; PKG_DIR = `.ds-pkg`, so `srcDir`/`docsMap`/`guidelinesGlob`
  paths in config are relative to `.ds-pkg/`, hence the `../` prefixes).
- **Preview-only Tailwind classes need a CSS rebuild**: after adding classes in `.design-sync/previews/*.tsx`, re-run
  `build-ds.mjs` then `package-build.mjs`, otherwise the class doesn't exist in `_ds_bundle.css`.
- `next/link` / `next/image` are shimmed to `<a>` / `<img>` (`.design-sync/build/shims/`). `DynamicRouteMap` is
  excluded (only a `next/dynamic` wrapper of `LeafletRouteMap`).
- Fonts: the app loads them with `next/font/google`, and globals.css `@theme` defines `--font-sans: var(--font-sans), ...`
  (self-referential — only works because next/font sets the var on `<html>`). build-ds appends a `:root` block that
  resolves `--font-*` to Outfit / Anton / Bebas Neue / Geist Mono. IBM Plex Sans (fallback in `--font-sans`, AGENTS.md)
  is shipped too (user decision 2026-09-18).
- Groups come from category stubs in `.design-sync/groups/*.md` via `docsMap`.

## Resources shipped beyond components

- Icons: `.design-sync/build/icons.ts` (generated by `node .design-sync/build/gen-icons.mjs`) merges 59 curated lucide
  icons onto `window.EnviosDosRuedas` as `<Name>Icon` via `cfg.extraEntries`. Previews import icons from the DS package,
  never from 'lucide-react' — **each preview importing the lucide barrel costs ~90s of esbuild on this Windows/pnpm
  setup** (a full build once took 35+ min and looked hung). Deep subpath is `lucide-react/icons/<kebab>` (exports map).
- Guidelines: `.design-sync/guides/{tokens,voz-y-contenido,ejemplos}.md` + DESIGN.md via `guidelinesGlob`; ds.css
  `@source "../guides"` so every class used in the example snippets is compiled.
- `dtsPropsFor` for CTANestedPill / InputField / BentoGridItem / TimelineContent: the extractor drops inherited DOM props
  (placeholder, value, onChange, disabled, onClick...) that these components really forward.
- Card modes: RadioCardGroup and CardFooter are `cardMode: column` (flagged [GRID_OVERFLOW]).

## Toolchain

- Playwright: the cached Chromium on this machine is revision 1234 → `playwright@1.62.1` (1.63 wants 1243, not cached).
- Windows + Git Bash; `pnpm` is the repo's package manager (converter deps are isolated in `.ds-sync/` via npm).

## Known render warns

- `[FONT_MISSING] "Cambria"` — Tailwind's default `--font-serif` stack; the brand never uses serif. Suppressed via
  `runtimeFontPrefixes: ["Cambria"]` (user accepted it as a system fallback 2026-09-18).
- BentoGrid / BentoGridItem: `cardMode: column` + `viewport: 1100x900` so the lg 7/5 split renders (900px capture = tablet layout).

## Capture-harness gotchas (frozen clock) — handled in previews

- motion 12 runs opacity/filter/clipPath on WAAPI; with `page.clock.setFixedTime` the final inline `opacity:1` isn't
  committed before the screenshot. TimelineContent previews pass `onUpdate={() => {}}` (forces motion's JS path) + short
  tween `customVariants`. TimelineGroup's own container can't take that prop, so its preview pins
  `[style*="opacity"]` to 1 inside a scoped `data-tg-preview` wrapper. Live cards animate normally.
- Leaflet tile fade uses Date deltas → LeafletRouteMap preview forces `.leaflet-tile{opacity:1}` in a scoped style.
- Sparkles: `@tsparticles/react` throws "init callback must be stable" if a 2nd instance mounts before the engine loads
  (`particlesInit` recreated per render in src/components/ui/sparkles.tsx). The preview gates extra cells until a canvas
  exists. Latent app bug: hoist `particlesInit` to module scope.
- `public/` paths (`/logo-envios-simplified.webp`, used by LeafletRouteMap badge and LogosCarousel defaults) 404 outside the app →
  the next/image shim maps them to data URIs (build-ds `PUBLIC_ASSETS`). logo-master.svg is 4 MB (embedded raster), so it
  maps to `.design-sync/assets/logo-master-384.png`, a committed rasterization of the same file.
- BentoGridItem numeric `span` builds `md:col-span-${n}` dynamically → safelisted via `@source inline` in build/ds.css.

## Component findings worth reporting to the app owner (src untouched)

- VerticalCutReveal / TimelineContent clipUp mask each word with overflow-hidden: at `leading-[0.98]` Anton accents are
  clipped (ENVIÁ → ENVIA). Previews use line-height 1.25 / paddingTop 8.
- BentoGridItem's inner DoubleBezel panel doesn't stretch to the row height; previews pass `innerClassName="flex-1 flex flex-col"`
  via spread (not in `BentoGridItemProps`). Consider adding `innerClassName` to the props.
- CardHeader is `flex flex-col`: a Badge placed directly inside stretches full width — wrap it in a `<div>`.

## Re-sync risks

- `.design-sync/assets/logo-master-384.png` is derived from `public/logo-envios-simplified.webp`; regenerate it if the logo changes.
- Fonts are pinned copies of @fontsource 5.3.0 (latin subset) in `.design-sync/fonts/`.
- The Tailwind CSS scans the whole repo: new site classes flow into the bundle automatically; removed ones disappear.
- Preview workarounds above are tied to motion 12 / leaflet 1.9 / @tsparticles v4 behaviour — recheck after upgrades.
- Playwright pin (1.62.1) is tied to the locally cached Chromium 1234.
