Brand action button — blue `default` for primary actions, yellow `secondary` for the loud CTA.

```jsx
<Button size="hero" variant="secondary">Crear Cuenta →</Button>
```

Sizes `xl`/`hero` switch to Bebas Neue, uppercase, wide tracking (marketing CTAs). `square` drops the radius for the navbar "Cotizar Ya" block. Press state shrinks to 0.98.
