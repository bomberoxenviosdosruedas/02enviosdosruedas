# Paleta de Colores Oficial: Envíos DosRuedas (2026)

Este documento define la paleta oficial y exclusiva de colores para la identidad visual de **Envíos DosRuedas**. Únicamente se deben utilizar los colores y variaciones listados a continuación.

---

## 🔵 1. Azul EnviosDosruedas (Marca & Confianza)
Representa la presencia institucional, la seguridad y el orden de la infraestructura logística.

| Escala | Código Hex | Aplicación Sugerida |
| :--- | :--- | :--- |
| `50` | `#E6EEFE` | Fondos de alerta y estados ultra-claros |
| `100` | `#BACEFD` | Bordes suaves e indicadores inactivos |
| `200` | `#8EAFFB` | Enlaces secundarios y detalles visuales |
| `300` | `#628FF9` | Hover de estados interactivos |
| `400` | `#3570F8` | Elementos interactivos primarios |
| `500` | `#0950F6` | Azul de acento vibrante |
| `600` | `#0742CA` | Variación intermedia de estado |
| `700` | `#0636A5` | Azul corporativo primario (Header/Footer) |
