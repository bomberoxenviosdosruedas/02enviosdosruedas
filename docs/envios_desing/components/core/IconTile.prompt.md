Una línea: el chip amarillo con ícono que encabeza features, servicios y filas del footer.

```jsx
<IconTile name="Clock" animate="tilt" />
<IconTile name="ShieldCheck" tone="glass" size={40} />
```

Amarillo con sombra dura azul de 2px es el default; `tone="tint"` es la versión clara para fondo blanco. `animate="tilt"` reproduce el giro de 12° del bloque de Features.
