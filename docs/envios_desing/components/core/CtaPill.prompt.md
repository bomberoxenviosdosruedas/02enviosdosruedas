Una línea: el CTA insignia del sitio — píldora en mono con un círculo de ícono anidado.

```jsx
<CtaPill tone="yellow" href="#cta">Solicitar Servicio</CtaPill>
<CtaPill tone="ghost" href="#servicios">Ver Servicios</CtaPill>
```

Van de a pares: uno amarillo y uno fantasma. Es el único elemento del sistema en `--font-mono`.
