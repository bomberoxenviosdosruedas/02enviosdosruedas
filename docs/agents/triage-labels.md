# Triage Labels

The skills speak in terms of five canonical triage roles. This file maps those roles to the actual label strings used in this repo's local markdown issue tracker and aligns with `docs/marketing/TASKS.md`.

| Label in mattpocock/skills | Label in our tracker | Meaning in local workflow / `docs/marketing` |
| -------------------------- | -------------------- | --------------------------------------------- |
| `needs-triage`             | `needs-triage`       | Maintainer needs to evaluate this issue (`Pendiente`) |
| `needs-info`               | `needs-info`         | Waiting on owner / reporter clarification (`Bloqueado`) |
| `ready-for-agent`          | `ready-for-agent`    | Fully specified, prompt ready for an agent (`Specs listos`) |
| `ready-for-human`          | `ready-for-human`    | Requires human action (e.g. Canva kit, Google Business, contratos) |
| `wontfix`                  | `wontfix`            | Out of scope, rejected or superseded |

When a skill mentions a role (e.g. "apply the AFK-ready triage label"), use the corresponding label string from this table.
When updating items in `docs/marketing/TASKS.md`, refer to the mapped state.
